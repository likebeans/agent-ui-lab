## T1：事件、状态与预览

发送“帮我规划杭州三日游，喜欢慢节奏”，等待本轮完成，点击“追溯文字更新”，选中第 5 条 `TEXT_MESSAGE_CONTENT`。该事件的原始 `delta` 为 `杭州 3 天行程。`，同一 `messageId` 的 `text` 从：

```text
收到，我会用确定性 Agent 为你规划
```

变为：

```text
收到，我会用确定性 Agent 为你规划杭州 3 天行程。
```

只把实验事件中的 `delta` 改为 `内部预演增量`，点击“验证并试运行事件”，预览显示：

```text
收到，我会用确定性 Agent 为你规划内部预演增量
```

真实回复仍是原来的杭州 3 天文字。面板给出的源码链路为 `shared/agui.ts` 的 `aguiReducer` → `messages` → `AguiChatTurn` 文本段落；试运行只作用于候选状态，未修改真实协议记录或重新发起运行。

## T2：预算进入动作，错误保留有效表单

同一对话继续生成普通出行表单，打开 A2UI Workshop，载入“预算字段 + action.context”预设并应用。填写教学姓名“内部预演”和预算 `4200` 后提交，浏览器记录到一次真实 `POST /api/a2ui/action`，其中动作片段为：

```json
{
  "version": "v0.9.1",
  "action": {
    "name": "save_trip",
    "surfaceId": "trip-planner",
    "sourceComponentId": "submit",
    "context": {
      "destination": ["hangzhou"],
      "traveler": "内部预演",
      "days": "3",
      "budget": "4200"
    }
  }
}
```

上面为去除执行时间的记录片段。结果区域实际显示“已为 内部预演 生成 杭州 3 天游览计划，预算 4200 元（演示数据，未预订）。”，预算练习验证显示动作与状态一致。

随后载入“错误绑定路径（应拒绝）”并尝试应用，出现 `/form/notARealField` 不存在的错误。最后有效表单中的预算仍为 `4200`。打开 A2UI 教程，再通过浏览器返回，姓名、预算和错误反馈均保留，没有因文档往返新增提交。

此处改变输入框只更新本地模型；应用草稿先验证声明与绑定；点击“生成计划”才跨本地 HTTP 边界。Pages 的对应动作由浏览器内适配器处理，不能把本次本地 HTTP 证据直接用作 Pages 网络证据。

## T3：工具结果与布局资源

打开城市活动应用，初始杭州数据为“西湖清晨步道”。在实验 A 中选择成都并执行真实工具调用，活动变为“人民公园早茶”，原 iframe 仍连接。接着在实验 B 选择 `ui://intelligent-ui/trip-picker-list` 并重载，布局变为 `list`，新 iframe 完成握手，活动仍为成都数据。

| 实际操作            | 资源读取增量 | iframe 挂载增量 | 工具调用增量 | 实际结果                                |
| ------------------- | ------------ | --------------- | ------------ | --------------------------------------- |
| A：只换工具结果     | 0            | 0               | 1            | 成都活动进入原 App，原 iframe 保留      |
| B：读取另一布局资源 | 1            | 1               | 0            | 布局变为列表，iframe 重建，工具结果保留 |

原始 HTTP MCP 记录中，A 为 `tools/call` → `get_trip_activities`，参数为 `{ "city": "chengdu" }`；B 为 `resources/read`，URI 为 `ui://intelligent-ui/trip-picker-list`。工具 metadata 仍指向默认资源，实验 B 是 Host 显式选择已注册布局资源，没有更改工具 metadata。

阅读 [独立项目](../08-independent-project.md) 后，本次内部预演写出的有效输入为：


选择 A2UI 的理由是当前受支持的表单与动作子集足以表达只读准备查询。失败规则是查询失败或候选结果非法时保留草稿、最后有效结果及其输入快照，过期 `queryId` 不得覆盖新结果。查看准备事项不保留名额、不产生报名；本次没有实现或验收独立作业的 P1–P8。
